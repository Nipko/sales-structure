# Navegación, menú y Configuración

La barra lateral organiza Parallly por propósito: **Esenciales**, **IA y crecimiento**, **Operación**, **Insights** y **Administración**. **Configuración** permanece al final para que siempre tenga una ubicación estable. Las opciones visibles pueden variar según tu rol, plan e industria.

## Moverte sin perder el contexto

- Haz clic en el nombre de una sección para plegarla o desplegarla.
- Usa el buscador de comandos con `Ctrl+K` o `⌘K` para abrir una pantalla por nombre.
- Marca como favorito lo que uses con frecuencia; los accesos recientes ayudan a volver al trabajo anterior.
- Dentro de **Configuración**, usa el botón de regreso o la ruta visible para volver al índice de configuración. El botón Atrás del navegador también debe devolverte a la pantalla anterior, no al panel principal.

Si una opción no aparece, confirma primero tu rol, el vertical del negocio y las funciones habilitadas en **Configuración → Plan y facturación**. No cambies una configuración solo para hacerla visible sin confirmar con un administrador.

El tour de configuración se ancla a los elementos visibles del menú. Si la barra está plegada, ábrela antes de reiniciar el tour para ver cada paso alineado.

# Navegação, menu e Configurações

A barra lateral organiza a Parallly por objetivo: **Essenciais**, **IA e crescimento**, **Operação**, **Insights** e **Administração**. **Configurações** permanece no final para manter uma localização estável. As opções visíveis podem variar conforme seu perfil, plano e setor.

## Navegar sem perder o contexto

- Clique no nome de uma seção para recolher ou expandir.
- Use a busca de comandos com `Ctrl+K` ou `⌘K` para abrir uma tela pelo nome.
- Marque como favoritas as páginas frequentes; os itens recentes ajudam a voltar ao trabalho anterior.
- Dentro de **Configurações**, use o controle de voltar ou o caminho visível para retornar ao índice. O botão Voltar do navegador também deve retornar à tela anterior, não ao painel inicial.

Se uma opção não aparecer, confira primeiro seu perfil, o vertical do negócio e os recursos habilitados em **Configurações → Plano e faturamento**. Não altere uma configuração apenas para fazê-la aparecer sem confirmar com um administrador.

O tour de configuração se ancora nos itens visíveis do menu. Se a barra estiver recolhida, abra-a antes de reiniciar o tour para manter cada etapa alinhada.
